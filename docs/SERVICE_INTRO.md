### 1. AI 맞춤형 펫 워케이션 코스 생성

사용자가 입력한 반려견 정보와 워케이션 조건을 기반으로 강릉·춘천·원주 지역 내 반려견 동반 가능 장소를 조합하여 맞춤형 워케이션 코스를 생성한다. 코스에는 숙박, 업무 가능 장소, 음식점, 관광지, 산책 코스가 일정 흐름에 맞게 포함되어야 한다.

| 반려견 마리 수 | 필수 | 1 이상의 정수 |

### 2. 펫- 워크 지수 제공

장소별로 반려견 동반 적합도, 워케이션 적합도, 산책 접근성, 예측 혼잡도, 접근성, 응급 접근성을 종합하여 펫-워크 지수를 제공한다. 펫-워크 지수는 공공데이터에서 직접 제공되는 값이 아니라, 서버에서 계산하는 서비스 내부 점수이다.

- 적용 대상: STAY / WORK_PLACE / FOOD / TOUR (WALK·HOSPITAL은 지수 미적용)

- 처리 기준

| 평가 항목 | 만점 | 설명 | 사용 데이터 |
| --- | --- | --- | --- |
| 반려견 동반 적합도 | 30점 | acmpyTypeCd(동반 유형), 보유 시설, 케이지 필수 여부 기준 | 반려동물 동반여행 서비스 /detailPetTour2 |
| 워케이션 적합도 | 25점 | PlaceType 기반 고정값 (WORK_PLACE 25 / STAY 18 / FOOD 8 / TOUR 5) | PlaceType |
| 산책 접근성 | 20점 | 가장 가까운 두루누비 코스까지 Haversine 거리 기준 | 두루누비 정보 서비스_GW |
| 예측 혼잡도 | 15점 | cnctrRate 기반 역방향 점수 (낮을수록 높음) | 관광지 집중률 방문자 추이 예측 정보 |
| 응급 접근성 | 7점 | 가장 가까운 동물병원까지 Haversine 거리 기준 | GWTO PC05 동물병원 데이터 |

### 8. 지역 선택 및 장소 간 거리 계산

사용자는 강릉, 춘천, 원주 중 원하는 지역을 직접 선택하고, 서버는 선택된 지역을 기준으로 장소 목록 조회와 코스 생성을 처리한다. 거리 정보는 사용자 현재 위치 기준이 아니라, 장소와 장소 사이의 거리를 계산하는 데 사용한다.

- 지역 선택 처리 기준

| 항목 | 내용 |
| --- | --- |
| 지역 선택 방식 | 사용자가 강릉 / 춘천 / 원주 중 직접 선택 |
| 장소 조회 기준 | 사용자가 선택한 지역 기준 |
| 코스 생성 기준 | 선택 지역 내 장소 데이터 기준 |
| 거리 계산 기준 | 코스에 포함된 장소 간 거리 |
| 지도 표시 기준 | 장소 데이터의 위도/경도 좌표 |

백엔드 처리 기준

| 처리 항목 | 내용 |
| --- | --- |
| 지역 선택 저장 | 사용자가 선택한 지역을 장소 목록 조회 조건 또는 코스 생성 요청값으로 사용 |
| 장소 목록 조회 | 선택 지역에 해당하는 장소만 조회 |
| 지도 표시 | 장소별 위도/경도 좌표를 반환하여 지도에 핀 표시 |
| 거리 계산 | 사용자 위치가 아닌 장소 간 좌표를 기준으로 계산 |
| 코스 동선 계산 | 이전 장소와 다음 장소 사이의 직선거리를 계산하여 반환 |
| 정렬 기준 | 지역 내 장소 목록은 펫-워크 지수순, 혼잡도 낮은 순, 최신순 기준으로 정렬 |
| 사용자 위치 기준 거리순 정렬 | 제공하지 않음 |
- 사용 데이터/API

| 데이터/API | 사용 목적 |
| --- | --- |
| 카카오 지도 API | 선택 지역 내 장소 핀 표시, 코스 동선 지도 표시 |
| 카카오 로컬 API | 주소-좌표 변환, 장소 좌표 보정, 장소 간 거리 계산 기준 좌표 확보 |
| 서비스 내부 장소 DB | 지역별 장소 목록 조회 |
| 서비스 내부 코스 DB | 코스 내 장소 순서 및 거리 저장 |

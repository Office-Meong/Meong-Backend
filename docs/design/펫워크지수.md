# 펫-워크 지수 설계

## 개요

- 총점: 100점
- 등급: A(85+) / B(70~84) / C(55~69) / D(40~54) / E(~39)
- 적용 대상: STAY / WORK_PLACE / FOOD / TOUR
- 미적용 대상: WALK (코스 자체가 산책), HOSPITAL (응급 시설 자체)
- 계산 주체: 서버 (DB 적재 시 또는 API 승인 후 배치 계산)

---

## 항목별 점수 설계

### 1. 반려견 동반 적합도 (30점 만점)

**데이터 소스**: KorPetTourService2 `/detailPetTour2`

| 조건 | 점수 |
|---|---|
| `acmpyTypeCd` = 실내 동반 가능 | 30점 |
| `acmpyTypeCd` = 실내외 모두 가능 | 24점 |
| `acmpyTypeCd` = 실외/지정 장소만 | 18점 |
| `acmpyTypeCd` 없음 (기본) | 15점 |
| `relaPosesFclty`에 급수대 포함 | +1점 |
| `relaPosesFclty`에 배변봉투 포함 | +1점 |
| `relaPosesFclty`에 펫 전용 공간 포함 | +1점 |
| `acmpyNeedMtr`에 케이지 필수 언급 | -3점 |

최대 33점 → 30점으로 cap 처리

---

### 2. 워케이션 적합도 (25점 만점)

**데이터 소스**: PlaceType 기반 고정값

wifi/좌석 등 상세 데이터 소스 없음 → PlaceType으로 판단

| PlaceType | 점수 |
|---|---|
| WORK_PLACE | 25점 |
| STAY | 18점 |
| FOOD | 8점 |
| TOUR | 5점 |

---

### 3. 산책 접근성 (20점 만점)

**데이터 소스**: 두루누비 코스 DB → Haversine 거리 계산

장소 좌표와 두루누비 코스 시작점 좌표 간 최소 거리 기준

| 최소 거리 | 점수 |
|---|---|
| 500m 이내 | 20점 |
| 500m ~ 1km | 15점 |
| 1km ~ 2km | 10점 |
| 2km ~ 3km | 5점 |
| 3km 초과 | 2점 |
| 데이터 없음 (fallback) | 5점 |

---

### 4. 예측 혼잡도 (15점 만점)

**데이터 소스**: 관광지집중률 API `cnctrRate` (낮을수록 높은 점수 → 역방향)

| 혼잡도 등급 | cnctrRate 범위 | 점수 |
|---|---|---|
| RELAXED | ~25% | 15점 |
| NORMAL | 25 ~ 50% | 11점 |
| CROWDED | 50 ~ 75% | 7점 |
| VERY_CROWDED | 75%~ | 3점 |
| UNKNOWN (데이터 없음/fallback) | - | 8점 |

> cnctrRate 임계값은 API 승인 후 실제 분포 확인 시 조정 예정

---

### 5. 응급 접근성 (7점 만점)

**데이터 소스**: GWTO PC05 동물병원 좌표 → Haversine 거리 계산

| 가장 가까운 동물병원까지 거리 | 점수 |
|---|---|
| 1km 이내 | 7점 |
| 1km ~ 3km | 5점 |
| 3km ~ 5km | 3점 |
| 5km ~ 10km | 2점 |
| 10km 초과 | 1점 |

---

### 6. 접근성 (3점 만점)

**데이터 소스**: 무장애여행 API

| 조건 | 점수 |
|---|---|
| 주차 가능 | +1점 |
| 유모차 사용 가능 | +1점 |
| 경사로 있음 | +1점 |
| 데이터 없음 (fallback) | 0점 |

---

## 최종 점수 산출

```
펫-워크 지수 = 반려견 동반 적합도 + 워케이션 적합도 + 산책 접근성
             + 예측 혼잡도 + 응급 접근성 + 접근성
```

---

## API 승인 현황 및 fallback 전략

| 항목 | API | 현재 상태 | fallback |
|---|---|---|---|
| 반려견 동반 적합도 | KorPetTourService2 | ✅ 승인됨 | - |
| 워케이션 적합도 | PlaceType 내부 | ✅ 항상 가능 | - |
| 산책 접근성 | 두루누비 | ❌ 신청 필요 | 5점 고정 |
| 예측 혼잡도 | 관광지집중률 | ❌ 신청 필요 | 8점 고정 |
| 응급 접근성 | GWTO PC05 | ✅ 승인 불필요 (인증 없음) | - |
| 접근성 | 무장애여행 | ❌ 신청 필요 | 0점 |

두루누비·관광지집중률·무장애여행 API 미승인 상태 기본 점수:
- 반려견 동반 적합도(최대 30) + 워케이션 적합도(최대 25) + 산책 접근성(5) + 예측 혼잡도(8) + 응급 접근성(최대 7) + 접근성(0) = 최대 75점

| 강릉 | 30개 (GWTO 식음료 전체) + KTO 별도 | 13개 (GWTO 포함) | 12개 |
| 춘천 | 46개 (GWTO 식음료 전체) | 미확인 | 11개 |

## 장소 유형별 제공 정보 항목

| 정보 항목 | KTO 소스 (STAY/WORK_PLACE/FOOD/TOUR) | GWTO 소스 (WORK_PLACE/FOOD/HOSPITAL) |
|---|---|---|
| 반려견 동반 가능 여부 | ✅ `acmpyTypeCd` (상세 코드) | ✅ `petFlag` (Y/N) |
| 동반 조건 / 유의사항 | ✅ `acmpyNeedMtr`, `etcAcmpyInfo` | ✅ `policyCautions` (통합 텍스트) |
| 이용 가능 공간 | ✅ `relaPosesFclty`, `inOutFlag` | ✅ `inOutFlag`, `mainFacility`, `petFacility` |
| 운영시간 | ✅ `/detailIntro2` 별도 호출 | ✅ `usedTime` (단일 필드) |
| 휴무일 | ✅ `/detailIntro2` 별도 호출 | ✅ `usedTime` 안에 포함 (파싱 필요) |
| 주차 가능 여부 | ✅ `/detailIntro2` 별도 호출 | ✅ `parkingFlag` (Y/N) |
| 전화번호 | ✅ `tel` | ✅ `tel` |
| 이미지 | ✅ `firstimage` / `/detailImage2` | ✅ `imageList` (HTTP URL, Android 설정 필요) |
| 예측 혼잡도 | ⚠️ 관광지집중률 API (미승인, 소규모 장소 UNKNOWN 가능성) | ⚠️ 동일 |
| 접근성 (경사로) | ❌ 무장애여행 API (미승인) | ❌ GWTO 미제공 |
| 접근성 (유모차) | ✅ `chkbabycarriage` (관광지 타입만) | ❌ GWTO 미제공 |

> GWTO는 단일 `/detailSeqPart.do` 호출로 대부분의 정보를 제공. 자세한 필드 정의는 `docs/api/GWTO.md` 참고.

# 한국관광공사_관광지별 연관 관광지 정보 API 분석

## 기본 정보

- 데이터 포맷: JSON / XML (`_type=json`)
- 공통 필수 파라미터: `serviceKey`, `MobileOS`, `MobileApp`, `pageNo`, `numOfRows`, `baseYm`, `areaCd`, `signguCd`
- 데이터 성격: 실제 방문 패턴 기반 연관 관광지 순위 (과거 월 단위 데이터)

---

## 엔드포인트 목록 및 활용 계획

### ✅ 주요 활용 엔드포인트

#### 1. `GET /areaBasedList1` — 지역기반 연관 관광지 목록 조회
특정 지역(areaCd + signguCd) 내 전체 관광지에 대한 연관 관광지 순위 목록 조회.

**요청 파라미터**

| 파라미터 | 필수 | 설명 |
|---|---|---|
| baseYm | 필수 | 기준 년월 (YYYYMM) |
| areaCd | 필수 | 관광지 지역 코드 (집중률 API와 동일 코드 체계로 추정) |
| signguCd | 필수 | 관광지 시군구 코드 |

---

#### 2. `GET /searchKeyword1` — 키워드 검색 연관 관광지 조회
특정 관광지명(keyword)으로 검색하여 해당 관광지의 연관 관광지 순위 조회.

**요청 파라미터**: `/areaBasedList1`과 동일 + `keyword`(관광지명, 필수)

---

### 공통 응답 필드

| 필드 | 설명 | 서비스 활용 |
|---|---|---|
| tAtsNm | 기준 관광지명 | 연관 정보의 기준 장소 |
| tAtsCd | 기준 관광지 코드 | 자체 코드 (contentId 아님) |
| areaCd / areaNm | 기준 관광지 지역 | - |
| signguCd / signguNm | 기준 관광지 시군구 | - |
| rlteTatsNm | 연관 관광지명 | 대체/추가 장소 후보 탐색 |
| rlteTatsCd | 연관 관광지 코드 | 자체 코드 (contentId 아님) |
| rlteRegnCd / rlteRegnNm | 연관 관광지 지역 | 같은 지역 필터링 가능 |
| rlteSignguCd / rlteSignguNm | 연관 관광지 시군구 | 같은 시군구 필터링 가능 |

| rlteCtgryMclsNm | 연관 관광지 카테고리 중분류 | - |
| rlteCtgrySclsNm | 연관 관광지 카테고리 소분류 | - |
| baseYm | 기준 년월 | 데이터 최신성 판단 |

## 서비스 활용 계획

### 대체 장소 추천 시 활용
사용자가 코스 내 장소를 교체 요청할 때, 연관 관광지 순위를 참고하여 후보 목록 생성.

```
1. 교체 요청 장소의 tAtsNm으로 /searchKeyword1 호출
2. rlteRank 순서로 연관 관광지 목록 확인
3. 같은 지역(rlteSignguCd) + 반려동물 동반 가능 여부 교차 검증
4. 조건 충족 장소를 대체 후보로 반환
```

### 코스 후보 확장 시 활용
AI 코스 생성 단계에서 장소 풀(pool)을 확장하는 데 참고 데이터로 활용.

## 갭 분석 (핵심 이슈)

| 필요 정보 | 문제 | 해결 방안 |
|---|---|---|
| contentId 연결 | `tAtsCd`/`rlteTatsCd`는 자체 코드로 contentId 아님 | `tAtsNm`/`rlteTatsNm`으로 반려동물 API 장소 DB 텍스트 매핑 |
| 반려동물 동반 가능 여부 | 이 API는 방문 패턴 기반으로 반려동물 조건 미포함 | 반려동물 API DB에서 교차 검증 필수 |
| 월 단위 데이터 | `baseYm` 필수로 실시간 연관 관광지 없음 | 가장 최근 월 데이터를 주기적으로 수집 |
| areaCd/signguCd 코드 체계 | 집중률 API와 동일 코드 추정, 확인 필요 | 매뉴얼 시군구 코드 파일로 확인 |

---

## 활용 우선순위 재검토

이 API의 연관 관광지는 **일반 관광객의 방문 패턴** 기반이므로:
- 반려동물 동반 불가 장소도 연관 관광지로 포함될 수 있음
- 반려동물 API DB에서 교차 검증 후 동반 가능 장소만 필터링하는 로직 필수
- 단독으로 사용 시 서비스 목적에 맞지 않을 수 있으며, 반드시 보조 데이터로 활용

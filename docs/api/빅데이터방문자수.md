# 한국관광공사_관광빅데이터 지역별 방문자수 API 분석

## 기본 정보

- 데이터 포맷: JSON
- 공통 필수 파라미터: `serviceKey`, `MobileOS`, `MobileApp`, `startYmd`, `endYmd`
- 데이터 성격: 일별 지역 단위 방문자 수 집계 (과거 데이터)
- 활용 목적: 관리자 분석, 서비스 성과 분석, 추천 로직 고도화 (실시간 코스 생성에 미사용)

---

## 엔드포인트 목록

### 1. `GET /metcoRegnVisitrDDList` — 광역 지자체 방문자수 조회 (시도 단위)

**요청 파라미터**

| 파라미터 | 필수 | 설명 |
|---|---|---|
| startYmd | 필수 | 시작 연월일 (YYYYMMDD) |
| endYmd | 필수 | 종료 연월일 (YYYYMMDD) |

**응답 필드**

| 필드 | 설명 | 비고 |
|---|---|---|
| baseYmd | 기준 날짜 | 일별 집계 |
| areaCode | 지역 코드 | 시도 단위 (강원도 코드 확인 필요) |
| areaNm | 지역명 | 예: 강원도 |
| daywkDivCd | 요일 구분 코드 | 평일/주말 등 |
| daywkDivNm | 요일 구분명 | |
| touDivCd | 관광객 구분 코드 | 내국인/외국인 등 추정 |
| touDivNm | 관광객 구분명 | |
| touNum | 방문자 수 | |

---

### 2. `GET /locgoRegnVisitrDDList` — 기초 지자체 방문자수 조회 (시군구 단위) ★ 주요 활용

우리 서비스 MVP 대상인 강릉/속초/양양 시군구 단위 방문자 수 조회 가능.

**응답 필드**

| 필드 | 설명 | 서비스 활용 |
|---|---|---|
| baseYmd | 기준 날짜 | 날짜별 방문 추이 분석 |
| signguCode | 시군구 코드 | 강릉/속초/양양 필터 기준 |
| signguNm | 시군구명 | |
| daywkDivCd | 요일 구분 코드 | 요일별 방문 패턴 분석 |
| daywkDivNm | 요일 구분명 | |
| touDivCd | 관광객 구분 코드 | 방문자 유형 |
| touDivNm | 관광객 구분명 | |
| touNum | 방문자 수 | 지역 방문 수요 지표 |

## 서비스 내 활용 범위

| 활용 목적 | 사용 엔드포인트 | 비고 |
|---|---|---|
| 강릉/속초/양양 방문 추이 분석 | `/locgoRegnVisitrDDList` | 관리자 대시보드 |
| 요일별/시즌별 방문 패턴 파악 | `/locgoRegnVisitrDDList` | 코스 추천 로직 고도화 참고 |
| 공모전 성과 분석 자료 | 두 엔드포인트 모두 | 기간별 집계 |
| 강원도 전체 방문 현황 | `/metcoRegnVisitrDDList` | 서비스 수요 분석 |

> 코스 생성, 장소 상세, 혼잡도 계산 등 **실시간 사용자 기능에는 직접 미사용**

## 갭 분석

| 필요 정보 | 문제 | 해결 방안 |
|---|---|---|
| signguCode 코드 체계 | 다른 API의 sigunguCode와 동일 여부 불명확 | 강릉/속초/양양 코드값 확인 필요 |
| 장소별 방문자 수 | 지역 단위 집계만 제공, 개별 장소 데이터 없음 | 집중률 API로 장소별 혼잡도 대체 |
| 데이터 제공 기간 | 최신 데이터 제공 시점 불명확 (운영팀 문의 필요) | API 호출로 최신 날짜 확인 |
| 실시간성 | 과거 집계 데이터만 제공 | 실시간 수요 파악 불가, 트렌드 분석만 가능 |

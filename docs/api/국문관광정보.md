# 한국관광공사_국문 관광정보 서비스 API 분석

## 기본 정보

- 데이터 포맷: JSON / XML (`_type=json`)
- 공통 필수 파라미터: `serviceKey`, `MobileOS`, `MobileApp`
- **지역 필터 코드 체계 변경**: `areaCode`/`sigunguCode`/`cat1~3` 모두 삭제 예정
  - → `lDongRegnCd`/`lDongSignguCd` (법정동 코드) + `lclsSystm1~3` (분류체계 코드) 사용

---

## 엔드포인트 목록 및 활용 계획

### ✅ 주요 활용 엔드포인트

#### 1. `GET /detailPetTour2` — 반려동물 동반 여행 정보 ⚠️ 중요
반려동물동반여행 API의 `/detailPetTour2`와 동일한 이름이지만 동작이 다름.
**contentId가 선택 파라미터** → contentId 없이 전체 목록 조회 가능.

**요청 파라미터**: `contentId` (선택, 미입력 시 전체 목록)

**응답 필드**: 반려동물동반여행 API와 동일

| 필드 | 설명 |
|---|---|
| contentid | 콘텐츠ID |
| acmpyNeedMtr | 동반 필요 사항 (목줄, 케이지 등) |
| acmpyPsblCpam | 동반 가능 반려동물 |
| acmpyTypeCd | 동반 유형 코드 |
| relaAcdntRiskMtr | 사고 위험 사항 |
| relaPosesFclty | 보유 시설 |
| relaFrnshPrdlst | 구비 용품 |
| etcAcmpyInfo | 기타 동반 정보 |
| relaPurcPrdlst | 구매 용품 |
| relaRntlPrdlst | 임대 용품 |

> 반려동물 API의 `/detailPetTour2`는 contentId 필수(개별 조회만 가능), 이 API는 contentId 선택(전체 목록 조회 가능) — DB 초기 적재 시 활용 가능

---

#### 2. `GET /areaBasedList2` — 지역기반 관광정보 조회
반려동물 API 장소 DB 보완용. 기본 관광정보 수집.

**지역 필터 사용 방법** (삭제 예정 파라미터 제외)

| 파라미터 | 설명 |
|---|---|
| lDongRegnCd | 법정동 시도코드 |
| lDongSignguCd | 법정동 시군구코드 |
| lclsSystm1~3 | 분류체계 코드 |
| contentTypeId | 관광타입 (12/14/28/32/38/39) |

**응답 필드**: 반려동물 API `/areaBasedList2`와 동일 (contentid, title, addr, mapx, mapy, tel, firstimage 등)

---

#### 3. `GET /detailCommon2` — 공통 정보 조회
contentId 기준으로 개요, 홈페이지 등 상세 정보 보완.

| 필드 | 서비스 활용 |
|---|---|
| overview | 장소 개요 설명 |
| homepage | 공식 홈페이지 URL |
| telname | 전화번호 명칭 |

---

#### 4. `GET /detailIntro2` — 소개 정보 조회
운영시간, 휴무일, 주차, 반려동물 허용 여부 조회. 반려동물 API와 동일 구조.

**추가 필드** (반려동물 API에 없는 것)

| 필드 | 설명 | 서비스 활용 |
|---|---|---|
| theme | 여행 코스 테마 | 코스 분류 참고 |
| schedule | 일정 정보 | 여행 코스 타입 정보 |
| taketime | 소요 시간 | 코스 소요 시간 |
| distance | 거리 | 코스 거리 |

---

#### 5. `GET /searchStay2` — 숙박 정보 조회
숙박 타입 전용 검색. `lDongRegnCd` 필수.
STAY 타입 장소 목록 수집에 특화된 엔드포인트.

---

#### 6. `GET /searchFestival2` — 행사 정보 조회
행사 시작일(`eventStartDate`) 기준 조회. 여행 기간 내 현지 행사 정보 포함 가능.

| 필드 | 설명 | 서비스 활용 |
|---|---|---|
| eventstartdate | 행사 시작일 | 여행 기간 교차 확인 |
| eventenddate | 행사 종료일 | - |
| progresstype | 진행 방식 | - |
| festivaltype | 행사 유형 | - |

---

#### 7. `GET /areaBasedSyncList2` — 관광정보 동기화 목록 조회
DB 동기화 시 변경된 콘텐츠 감지. `oldContentid` 파라미터로 이전 ID 기준 조회 가능.

| 필드/파라미터 | 설명 |
|---|---|
| showflag | 콘텐츠 표출 여부 |
| oldContentid | 이전 contentId (ID 변경 추적) |
| modifiedtime | 수정일 기준 필터 |

## 반려동물 API와의 역할 분담

| 역할 | 반려동물동반여행 API | 국문 관광정보 API |
|---|---|---|
| 반려동물 동반 장소 목록 | `/areaBasedList2` (주) | 보조 |
| 반려동물 동반 조건/유의사항 | `/detailPetTour2` (contentId 필수) | `/detailPetTour2` (전체 목록 조회 가능) |
| 장소 기본 정보 보완 | - | `/detailCommon2` (overview, homepage) |
| 운영시간/휴무일 | `/detailIntro2` | `/detailIntro2` (동일) |
| 행사 정보 | 없음 | `/searchFestival2` |
| 숙박 전용 검색 | - | `/searchStay2` |
| DB 동기화 | `/petTourSyncList2` | `/areaBasedSyncList2` |

## 코드 체계 변경 주의사항

| 구분 | 반려동물동반여행 API | 국문 관광정보 API |
|---|---|---|
| 지역 코드 | `areaCode` (예: 32=강원도) | `lDongRegnCd` (법정동 코드) |
| 시군구 코드 | `sigunguCode` | `lDongSignguCd` |
| 분류 코드 | `cat1`/`cat2`/`cat3` | `lclsSystm1`/`lclsSystm2`/`lclsSystm3` |

→ 두 API를 함께 사용할 때 지역 필터 코드를 각각 다르게 적용해야 함
→ `ldongCode2`로 법정동 코드, `lclsSystmCode2`로 분류체계 코드 사전 조회 필요

---

## DB 적재 전략

```
1. 반려동물 API /areaBasedList2로 강릉/속초/양양 반려동물 동반 장소 contentId 수집
2. 국문 관광정보 API /detailCommon2로 overview, homepage 보완
3. 국문 관광정보 API /detailPetTour2 (contentId 미입력)로 전체 반려동물 동반 조건 일괄 수집 검토
4. /areaBasedSyncList2로 정기 동기화 시 변경된 장소 감지
5. /searchFestival2로 여행 기간 내 현지 행사 정보 수집 (선택적)
```

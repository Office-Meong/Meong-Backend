# 한국관광공사_관광지 집중률 방문자 추이 예측 정보 API 분석

## 기본 정보

- 데이터 포맷: JSON / XML (`_type=json`)
- 공통 필수 파라미터: `serviceKey`, `MobileOS`, `MobileApp`, `pageNo`, `numOfRows`, `areaCd`, `signguCd`
- 제공 범위: 향후 30일 관광지별 집중률 예측

---

## 엔드포인트

### `GET /tatsCnctrRatedList` — 관광지 집중률 정보 목록 조회

**요청 파라미터**

| 파라미터 | 필수 | 설명 | 비고 |
|---|---|---|---|
| areaCd | 필수 | 관광지 지역코드 | 반려동물 API의 areaCode와 다른 코드 체계일 수 있음 |
| signguCd | 필수 | 관광지 시군구코드 | 매뉴얼 내 '관광지시군구코드정보' 파일 참고 필요 |
| tAtsNm | 선택 | 관광지명 검색 | 이름 기반 검색 |

**응답 필드**

| 필드 | 설명 | 서비스 활용 |
|---|---|---|
| tAtsNm | 관광지명 | 장소 매핑 키 (이름 기반) |
| cnctrRate | 집중률 | 혼잡도 등급 산출 기준값 |
| baseYmd | 기준일자 | 예측 날짜 (향후 30일) |
| areaCd | 지역코드 | - |
| areaNm | 지역명 | - |
| signguCd | 시군구코드 | - |
| signguNm | 시군구명 | - |

---

## 서비스 혼잡도 등급 산출 계획

`cnctrRate` 값을 기준으로 내부 등급 변환 (실제 분포 확인 후 임계값 확정 필요)

| cnctrRate 범위 (예상) | 서비스 등급 |
|---|---|
| ~ 25% | RELAXED |
| 25 ~ 50% | NORMAL |
| 50 ~ 75% | CROWDED |
| 75% ~ | VERY_CROWDED |
| 데이터 없음 | UNKNOWN |

> cnctrRate의 실제 값 범위(절댓값인지 상대값인지)는 API 호출 후 확인 필요

## 핵심 이슈 ⚠️

### 1. 장소 식별자 연결 불가
이 API는 `tAtsNm`(관광지명)만 제공하며 `contentId` 같은 공통 식별자가 없음.
반려동물동반여행 API의 `title`(장소명)과 텍스트 매핑을 시도해야 하나, 이름 불일치 위험 있음.

**해결 방안 비교**

| 방안 | 장점 | 단점 |
|---|---|---|
| tAtsNm ↔ title 텍스트 매핑 | 장소별 혼잡도 표시 가능 | 이름 불일치 시 매핑 실패 |
| 지역(areaCd+signguCd) 단위 집중률 → 지역 내 전체 장소 적용 | 매핑 실패 없음 | 장소별 세분화 불가 |
| 매핑 가능한 장소만 표시, 나머지 UNKNOWN | 정확한 데이터만 표시 | 대부분 UNKNOWN이 될 수 있음 |

**권장:** 초기에는 지역 단위 집중률 적용, 이후 데이터 확인 후 장소별 매핑 시도

---

### 2. 코드 체계 — 확인 완료

강원특별자치도 기준 (KorPetTourService2의 areaCode/sigunguCode와 다른 체계)

| 지역 | areaCd | signguCd | 데이터 건수 (30일치) |
|---|---|---|---|
| 강원특별자치도 | 51 | — | — |
| 강릉시 | 51 | 51150 | 2,880건 (~96개 관광지) |
| 춘천시 | 51 | 51110 | 1,800건 |
| 원주시 | 51 | 51130 | 1,650건 |

---

### 3. 향후 30일 데이터 구조 확인 필요
응답에 `baseYmd`(기준일자) 필드가 있으므로 30일치 데이터가 날짜별 다건으로 응답될 것으로 예상.
→ 날짜 기준 필터링 또는 평균값 산출 로직 필요.

---

## DB 적재 전략

```
1. areaCd + signguCd 기준으로 강릉/속초/양양 집중률 데이터 조회
2. baseYmd 기준 향후 30일 데이터를 날짜별로 저장
3. 코스 생성 요청 시 여행 날짜에 해당하는 cnctrRate 조회
4. cnctrRate → 혼잡도 등급 변환 후 장소에 적용
```

## 갭 분석

| 필요 정보 | 문제 | 해결 방안 |
|---|---|---|
| contentId 기반 장소 매핑 | 없음 | tAtsNm ↔ title 텍스트 매핑 또는 지역 단위 적용 |
| cnctrRate 값 범위 | 실제 확인 완료 | 평일 20~55%, 주말 70~83% (강릉 기준) |
| 지역코드 | 확인 완료 | areaCd=51 고정, signguCd는 위 표 참고 |
| 카페 등 소규모 장소 포함 여부 | 강릉 96개 관광지 중 카페는 2~3개만 포함 | 미포함 장소는 UNKNOWN(8점) fallback 처리 |

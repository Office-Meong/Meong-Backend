# 한국관광공사_두루누비 정보 서비스 API 분석

## 기본 정보

- 데이터 포맷: JSON
- 공통 필수 파라미터: `serviceKey`, `MobileOS`, `MobileApp`
- brdDiv: 현재 걷기 길(`DNWW`)만 제공

---

## 엔드포인트 목록 및 활용 계획

### ✅ 주요 활용 엔드포인트

#### 1. `GET /courseList` — 코스 목록 정보 조회
산책 코스 목록의 핵심 엔드포인트. 코스명/난이도/길 고유번호로 필터링.

**요청 파라미터**

| 파라미터 | 설명 | 비고 |
|---|---|---|
| crsKorNm | 코스명 검색 | 선택 |
| routeIdx | 길 고유번호 | 선택, routeList와 연결 키 |
| crsLevel | 난이도 | 1=하, 2=중, 3=상 |
| brdDiv | 걷기/자전거 구분 | DNWW=걷기 (현재 걷기만 제공) |

**응답 필드**

| 필드 | 설명 | 서비스 활용 |
|---|---|---|
| crsIdx | 코스 고유번호 | 내부 walkId 연결 키 |
| routeIdx | 길 고유번호 | routeList 연결 키 |
| crsKorNm | 코스명 | 산책 코스명 표시 |
| crsSummary | 코스 요약 | 코스 간단 설명 |
| crsContents | 코스 내용 | 코스 상세 설명 |
| crsTourInfo | 코스 관광 정보 | 주변 관광 정보 |
| travelerinfo | 여행자 정보 | 이용 안내 |
| crsDstnc | 코스 거리 | 산책 거리 표시 |
| crsTotlRqrmHour | 총 소요 시간 | 산책 소요 시간 표시 |
| crsLevel | 난이도 | 1=하, 2=중, 3=상 |
| crsCycle | 순환 여부 | 원점 회귀 여부 |
| sigun | 시군 | 지역 필터링 기준 (강릉/속초/양양) |
| gpxpath | GPX 파일 경로 | 코스 좌표 데이터 (시작점 추출 필요) |
| brdDiv | 걷기/자전거 구분 | DNWW=걷기 |
| createdtime | 생성일 | - |
| modifiedtime | 수정일 | - |

#### 2. `GET /routeList` — 길 목록 정보 조회
길(테마) 단위 목록 조회. 코스들이 속한 상위 길 정보 제공.

**요청 파라미터**

| 파라미터 | 설명 | 비고 |
|---|---|---|
| themeNm | 길 명 검색 | 선택 |
| brdDiv | 걷기/자전거 구분 | DNWW=걷기 |

**응답 필드**

| 필드 | 설명 | 서비스 활용 |
|---|---|---|
| routeIdx | 길 고유번호 | courseList 연결 키 |
| themeNm | 길 명 | 길 이름 표시 (예: 바우길) |
| linemsg | 한줄 소개 | 길 간단 설명 |
| themedescs | 길 설명 | 길 상세 설명 |
| brdDiv | 걷기/자전거 구분 | - |

## 서비스 필드 매핑표

| 서비스 표시 정보 | API 필드 | 출처 엔드포인트 |
|---|---|---|
| 산책 코스명 | crsKorNm | /courseList |
| 코스 설명 | crsSummary, crsContents | /courseList |
| 코스 거리 | crsDstnc | /courseList |
| 소요 시간 | crsTotlRqrmHour | /courseList |
| 난이도 | crsLevel | /courseList |
| 지역 (강릉/속초/양양) | sigun | /courseList (응답값 기준 필터) |
| 코스 좌표 | gpxpath → GPX 파싱 | /courseList |
| 속한 길 이름 | themeNm | /routeList (routeIdx 연결) |

---

## 데이터 연계 구조

```
routeList (길)
  └── routeIdx
        └── courseList (코스, 1개 길에 여러 코스)
              └── gpxpath → GPX 파일 다운로드 → 시작점 좌표 추출
```

## 갭 분석

| 필요 정보 | 문제 | 해결 방안 |
|---|---|---|
| 코스 시작점 위도/경도 | 직접 필드 없음 | gpxpath로 GPX 파일 다운로드 후 첫 번째 좌표 추출 |
| 지역 파라미터 필터 | API 요청 파라미터에 지역 필터 없음 | 전체 목록 조회 후 sigun 필드 기준으로 서버 필터링 |
| 반경 내 코스 검색 | 위치기반 조회 API 없음 | 코스 시작점 좌표를 DB에 저장 후 Haversine 거리 계산 |
| 이미지 | 코스 이미지 필드 없음 | 제공 안 됨 (대체 이미지 또는 지도 썸네일 활용 검토) |

## DB 적재 전략

두루누비 API는 위치기반 조회가 없으므로 아래 방식으로 처리 필요:

1. 서버 초기 적재 시 `/routeList` → `/courseList` 순으로 전체 데이터 수집
2. `sigun` 기준으로 강릉/속초/양양 코스만 필터링하여 내부 DB 저장
3. `gpxpath`에서 GPX 파일 파싱하여 시작점 위도/경도 추출 후 DB 저장
4. 펫-워크 지수 산책 접근성 계산 시 DB에 저장된 좌표 기준으로 Haversine 거리 계산
